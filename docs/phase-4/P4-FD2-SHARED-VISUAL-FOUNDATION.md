## Implementation

- Self-hosted official Adobe Source Sans 3 upright WOFF2 at 400, 600, and 700, and Source Serif 4 upright WOFF2 at 600, with their license notices in `public/fonts/`. Sans is the default interface family. Serif is referenced only by public editorial heading selectors. No runtime font CDN, font package, third designed family, or synthetic bold was added. Source assets: [Source Sans](https://github.com/adobe-fonts/source-sans) at `87b37a2daaed80fcb8e8ccb0085c4d72ddade12e` and [Source Serif](https://github.com/adobe-fonts/source-serif) at `80d3f8894c09c937bebfa9011247d2e1c79fd6f4`.
- Replaced the old global neutral and type tokens with the locked canvas `#EDF0F4`, white base, inset `#E3E8EF`, brand soft `#EEF0FF`, ink `#17233B`, secondary ink `#4A5870`, blue `#0D13CD`, yellow `#FCDF00`, border roles, 6/8/4px geometry, and bounded elevation. Semantic success, warning, danger, information, and neutral meanings remain separate. A short yellow identity keyline replaces decorative yellow notice dots.
- Added width roles for 120rem shell, 96rem wide work, 88rem dashboard, 76rem personal, 56rem detail, 44rem form, 42rem reading, 80rem public grid, and 28rem login. Feature root wrappers select a role without changing their data, controls, or route structure. Technology's account directory uses its wide region while selected mobile detail remains beside its selected record.
- Reworked the existing authenticated masthead, portal identity, 256px sidebar, selected navigation edge, Account affordance, and mobile drawer presentation. The drawer retains authorized links, switcher, scenario tools, Escape behavior, and focus return. A bounded Tab loop now keeps keyboard focus inside the open drawer.
- Restyled existing shared page/context headings, DemoNotice, buttons, links, controls, tabs, panels, tables, toolbars, badges, dialogs, and empty/error states. Long document/review dialogs have an internal scroll region and reachable actions. The public masthead is continuous, with one original seal. The Home, Programs, Admissions, and About page compositions remain for FD3.
- Added a neutral institutional 404 view and restyled the access-denied view. The 404 and 403 status/guard semantics were verified; no guard logic changed.
