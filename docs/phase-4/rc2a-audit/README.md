The bulk preview on 1 October was pre-existing and showed the Next development indicator. Copied runner strings saying “production” do not prove runtime mode. The dedicated sign-out confirmation and supplemental/Student controls on 2 October used `pnpm start` and the existing compiled build, without rebuilding. Installed Edge Chromium and Playwright were used throughout; no deployment or non-Chromium acceptance is implied.

The Student calendar mismatch compared the entire main text, including a changed selected day. It was resolved with a month-heading check in `student-controls.json`; no product change was needed. `coverage.cjs` now uses that heading assertion and the correct **View sample** document-action selector for future runs. The 238-check batch was not rerun after those harness corrections; the focused 13-check result is the resolution evidence.

All authenticated sessions were isolated. Sample profile/workflow changes were temporary browser state; sign-out requests alone were faulted. Actual credentials are not approved for publication. RC2B evidence belongs in a separate directory once implementation is authorized.
