# P4-FD3 — Public, Applicant, and Student Design Pass

**Status: PASS / COMPLETE — 30 September 2026.** This pass applies the [Final Visual Lock](P4-FINAL-VISUAL-LOCK.md) and [FD2 foundation](P4-FD2-SHARED-VISUAL-FOUNDATION.md) to the specified public and personal surfaces. [P4-UX-RULES.md](P4-UX-RULES.md) remains the behavior authority. FD4 has not started.

## Implementation

- Public Home, Programs, Admissions, and About now share an 80rem editorial rhythm, stronger section rules and canvas transitions, a continuous identity treatment below the existing campus photograph, and a dark institutional footer. The existing four-program tables, nested BSBA majors, journey, history, section order, links, and copy remain. The BSCpE code stays intact at mobile width. Login and account guidance use tighter vertical composition and the existing single seal.
- Applicant Dashboard places the current task first, then a ruled journey, quiet application facts, and plain notices. Application fields have clearer grouped sections and review/error hierarchy. DCAT and Enrollment status and document areas use the same task hierarchy while keeping their sample warnings, tabs, previews, and actions. Profile begins with identity and a local photo control, followed by ruled facts. The scenario switcher stays in the existing demo navigation area.
- Student Dashboard leads with the next class and Today agenda, followed by quieter enrollment and recent activity. Academics uses a flat tab baseline, stronger schedule divisions, and aligned date/time information. Calendar uses a date rail and agenda rules while keeping time strings together. Enrollment documents, Requests, and Announcements read as ruled lists. Profile begins with identity and academic context before ruled facts. Existing selectors, history, previews, actions, and local photo behavior remain.
- Presentation scoping is provided by a `data-section` attribute on the existing Applicant and Student page roots. No route, fixture, state machine, validation, search/filter/sort, auth/access, database, or workflow code changed. No package, new image, promotional copy, or school claim was added.
